# Data Engineering, Python, SQL, and Cloud Practice

This repository is a practical learning portfolio for data engineering. It combines Python programming, SQL, ETL pipelines, data modeling, interview preparation, and cloud-ready project design.

## Repository areas

- [`python/`](python/) - Python foundations, concurrency, machine learning examples, interview preparation, and small projects.
- [`sql/`](sql/) - Database schemas and SQL practice.
- [`data_engineering/`](data_engineering/) - Data engineering concepts, ETL projects, data generation, and utility scripts.
- [`cloud/`](cloud/) - Cloud architecture notes and future AWS, Azure, and GCP projects.
- [`data_engineering/data_generation/`](data_engineering/data_generation/) - Scripts for generating local practice datasets.

## Getting started

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Read [`QUICKSTART.md`](QUICKSTART.md) for the current study plan and runnable examples. Generated data, logs, Python caches, virtual environments, and IDE metadata are intentionally excluded from commits.
